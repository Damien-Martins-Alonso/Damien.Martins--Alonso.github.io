# Damien Martins--Alonso | ePortfolio

This is a ready-to-use, single-page portfolio website tailored to the ENSEEIHT CAM module requirements. It is inspired by a clean, modern, dark/light minimalistic aesthetic.

## How to use this with GitHub Pages

1. **Create a GitHub Account:** If you don't have one, sign up at [github.com](https://github.com/).
2. **Create a New Repository:** 
   - Name it something like `portfolio` or `damien-martins-alonso.github.io` (the latter makes it your default GitHub website).
   - Make sure the repository is **Public**.
3. **Upload Files:**
   - Unzip this folder on your computer.
   - Drag and drop `index.html`, `style.css`, and the `assets` folder directly into your new GitHub repository.
   - Click "Commit changes".
4. **Enable GitHub Pages:**
   - Go to the **Settings** tab of your repository.
   - On the left sidebar, click on **Pages**.
   - Under "Source", select the `main` (or `master`) branch and click Save.
   - Wait a minute or two, and GitHub will provide you with a live URL (e.g., `https://yourusername.github.io/portfolio/`).
   
## How to customize

- **Text:** Open `index.html` in any text editor (Notepad, VS Code) to change text, dates, and descriptions.
- **Photo:** Create an `assets` folder in your repository, upload your photo (e.g., `photo-profil.jpg`), and replace `<div class="image-placeholder">Photo Profil</div>` with `<img src="assets/photo-profil.jpg" alt="Profile" style="width: 300px; height: 300px; border-radius: 50%; object-fit: cover;">`.
- **CVs:** Upload your PDF CVs to the `assets` folder and ensure the links in `index.html` point to them (e.g., `<a href="assets/CV_EN.pdf">`).
- **Video:** In the Career section, replace the YouTube embed link (`https://www.youtube.com/embed/dQw4w9WgXcQ`) with your actual Elevator Pitch video link.
